## About The Project

This project explores how **deep neural networks** can be applied to **molecular simulation data** generated by **SIESTA** to predict potential energy and related electronic properties of **Si–C–H systems interacting with hydrogen**.  

- Phase 1 (TT1): Implemented the full data pipeline from **raw simulation outputs → data preprocessing → training with DeePMD-kit → prediction**. Built a CLI and an initial GUI wrapper. However, early models had high prediction error due to improper dataset aggregation.  
- Phase 2 (TT2): Improved dataset preparation, tuned hyperparameters (`rcut`, `rcut_smth`, descriptors, neuron counts), and achieved significantly better alignment between **predicted** and **simulated** results. Still limited by hardware (Google Colab Pro).  

The project contributes towards **accelerating materials discovery** by reducing reliance on costly first-principles simulations.

### Built With
* [DeePMD-kit](https://github.com/deepmodeling/deepmd-kit)  
* [dpdata](https://github.com/deepmodeling/dpdata)  
* [PyTorch](https://pytorch.org/) / [TensorFlow](https://www.tensorflow.org/)  
* [SIESTA](https://departments.icmab.es/leem/siesta/)  
* [Anaconda](https://www.anaconda.com/)  
* [Ubuntu 20.04](https://releases.ubuntu.com/focal/)

## Getting Started

### Requirements  
- Linux Ubuntu 20.04 (22.04 and 24.04 also)
- Miniconda already installed  
- Backend `ThesisMaster` cloned and environment variable `ROOT_WS_DUY` configured
> **Note:** The environment variable `ROOT_WS_DUY` must point to the directory where you cloned the project.  
> For example, if you cloned the code into `/home/user/my_workspace/ThesisMaster`, then set:  
> ```bash
> export ROOT_WS_DUY="/home/user/my_workspace"
> ```
  

### Installation
Clone the repo:
  ```bash
  git clone https://github.com/IricsDo/ThesisMaster.git
  cd ThesisMaster
  ```

### Setup environment:
1. Move to set up path:
  ```bash
  cd setups/linux
  ```
2. Run set up script:
  ```bash
  chmod +x setup.sh
  ./setup.sh
  ```
3. Activate environment:
  ```bash
  conda activate thesis-master
  ```

## Usage

The pipeline is controlled via `phase1/start.py`. It supports **training** and **predict-only** modes.

Before run, change to project path:
  ```bash
   cd $ROOT_WS_DUY/ThesisMaster
  ```

### Training Example
```bash
python3 phase1/start.py \
  -i /data/train_input \
  -o /data/train_out \
  -trainj /configs/train_config.json \
  -noh 4 10 19 28 52 55 58 100 112 \
  -pt -lps1 -v
```

### Make-Data Only
```bash
python3 phase1/start.py \
  -i /data/train_input \
  -o /data/train_out \
  -noh 4 10 19 28 52 55 58 100 112 \
  -omd -v
```

### Predict Example
```bash
python3 phase1/start.py \
  -pred_only \
  -mp /models/best/graph.pth \
  -p /data/predict_in \
  -v
```

For full argument reference (including conflicts, auto-detection rules, and error handling), see [ARGUMENTS.md](./ARGUMENTS.md).

## Appendix: `input.json` Configuration Guide  

### 1. `model`
```jsonc
"model": {
  "type_map": ["Si", "C", "H"],
  "descriptor": {
    "type": "se_e3",
    "rcut": 6.0,
    "rcut_smth": 0.5,
    "neuron": [50, 100, 200]
  },
  "fitting_net": {
    "neuron": [320, 320, 320]
  }
}
```

### 2. `loss`
```jsonc
"loss": {
  "pref_e": {"start": 0.02, "limit": 1},
  "pref_f": {"start": 1000, "limit": 1},
  "pref_v": {"start": 0, "limit": 0}
}
```

### 3. `learning_rate`
```jsonc
"learning_rate": {
  "start_lr": 0.001,
  "stop_lr": 1e-8,
  "decay_steps": 5000
}
```

### 4. `data`
```jsonc
"data": {
  "systems": ["./data/npy/"],
  "batch_size": 2,
  "numb_train": 20000,
  "numb_validation": 2000
}
```

### 5. `training`
```jsonc
"training": {
  "numb_steps": 1000000,
  "disp_freq": 1000,
  "save_freq": 10000,
  "save_dir": "./model/"
}
```

### 6. `validation`
```jsonc
"validation": {
  "systems": ["./data/valid/"],
  "batch_size": 2,
  "number_batch": 20
}
```

**Recommended Best Config:**  
- `descriptor.type`: se_e3  
- `descriptor.neuron`: [50, 100, 200]  
- `fitting_net.neuron`: [320, 320, 320]  
- `rcut = 6.0`, `rcut_smth = 0.5`

## Appendix: Descriptor Comparison  

| Descriptor | Characteristics | When to Use | Project Results (Si–C–H) |
|------------|-----------------|-------------|--------------------------|
| **`se_e2_a`** | Uses distance + angle (angular + radial). Provides full environment info. | Systems with many-body interactions but not strongly directional. | Performed reasonably well, but not as accurate as `se_e3`. |
| **`se_e3`** | Uses three-body information (bond angle). Strongly encodes directional interactions. | Systems with directional bonds (e.g., water, polymers, 2D materials). | **Best performing** for Si–C–H dataset. |
| **`dpa2`** | Multi-task, pre-trained on large datasets (LAM). | When fine-tuning from general models to system-specific. | Stable but not optimal for this system. |
| **`se_atten`** | Incorporates attention mechanism. Dynamically weights neighbors. | Complex chemical environments with diverse interactions. | Showed improvements, but still not better than `se_e3`. |

**Conclusion:**  
- Best for Si–C–H: **`se_e3`**  
- `se_e2_a`: good trade-off between speed and accuracy  
- `dpa2`: useful for multi-system training, requires more resources  
- `se_atten`: promising for broader chemical systems
